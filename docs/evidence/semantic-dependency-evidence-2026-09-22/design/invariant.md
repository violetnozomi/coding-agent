# Narrow evidence invariant

A semantic reviewer should be able to inspect bounded current implementation spans
for high-confidence unchanged direct callers already known to the production
structural repository graph. This is a supporting evidence capability, not a
promise of exhaustive call-graph coverage or successful semantic judgment.

The current user explicitly requests this channel. Historical source establishes
an asymmetric capability, not an older documented requirement to include every
caller. The RED therefore tests this narrow new product invariant. It does not
reclassify the historical model's omitted validation as a deterministic host bug.
Generic and frozen C tests first establish Main visibility, then fail specifically
at the missing Sidecar function body. No reviewer verdict is asserted.
