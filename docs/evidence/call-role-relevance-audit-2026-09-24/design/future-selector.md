# Eligibility is not semantic relevance

Candidate eligibility: changed implementation caller; resolved unchanged implementation
class target; trusted AST-native usage_role=returned; structural confidence >=0.85;
ready/indexed/current generation; safe source and explicit count/char budgets.

Yielded is structurally meaningful but exclude from initial selector until a separate
policy decision. Assigned and nested argument cases are omitted without tracing values.
Tests/docs/evaluator/authority paths remain excluded by future existing source safeguards.

This eligibility solves discarded-vs-returned ambiguity, not semantic boundary detection.
Returned TelemetryMarker remains eligible. No demonstrated host serialization/persistence
trigger exists. A generic optional structural-context policy is possible, but accepting
its false-positive boundary must be explicit, not described as proven semantic relevance.
