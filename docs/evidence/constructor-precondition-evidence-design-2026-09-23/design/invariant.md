# Candidate invariant

When semantic review concerns a changed serialization or persistence boundary,
and existing high-confidence structural intelligence locates a directly
related unchanged class definition, the host may expose a bounded source
envelope for that class as **supporting repository implementation evidence**.
The envelope is non-authoritative, current-workspace text, provenance-labeled,
deterministically selected, and fail-soft. It does not assert that an invalid
object was constructed and never replaces tests or task authority.
